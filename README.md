# 扎心测量 - 瓷片面积

一个用于现场记录地砖、墙砖、增加项和扣减项，并估算瓷片采购数量的网页。前端由 GitHub Pages 托管，账号与云端数据由 Supabase 提供。

## 功能

- 按户型、空间和墙面录入尺寸
- 自动计算铺贴面积、扣减项与净工程量
- 按瓷片规格和损耗率估算采购数量
- 在浏览器本地保存多个测量单元
- 使用邮箱和密码注册 / 登录，并将记录同步到云端
- 普通账号只能访问自己的记录，主账号可汇总查看全部账号的数据
- 主账号可查看全部测量明细并合并导出 XLSX
- 合并或单独导出 XLSX 统计表
- 打印或保存为 PDF

## 隐私

未登录时的数据通过浏览器 `localStorage` 保存在当前设备。登录后，测量记录会写入 Supabase 云端数据库，并按账号隔离；主账号可以查看全部账号的测量结果。浏览器本地仍保留一份缓存，以便网络中断时继续使用。

## 本地运行

前端不需要安装依赖。直接打开 `index.html`，或在项目目录启动任意静态文件服务器：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 部署

项目无需构建步骤，入口文件为仓库根目录的 `index.html`。仓库通过 GitHub Pages 从 `main` 分支根目录发布；后续修改并推送到 `main` 分支后会自动重新部署。

云端数据库结构位于 `supabase/schema.sql`。Supabase 项目的公开 URL 和 publishable key 保存在 `cloud-config.js`；这些值可以公开使用，真正的访问控制由数据库行级权限策略完成。

### 主账号

主账号在注册页填写私有的“主账号授权码”。授权码只保存在 Supabase 的私有 `app_admin_config` 表中，不写入本仓库。普通测试账号注册时留空即可。
