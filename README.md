# 扎心测量 - 瓷片面积

一个无需后端的工程量计算网页，用于现场记录地砖、墙砖、增加项和扣减项，并估算瓷片采购数量。

## 功能

- 按户型、空间和墙面录入尺寸
- 自动计算铺贴面积、扣减项与净工程量
- 按瓷片规格和损耗率估算采购数量
- 在浏览器本地保存多个测量单元
- 合并或单独导出 XLSX 统计表
- 打印或保存为 PDF

## 隐私

测量数据通过浏览器 `localStorage` 保存在当前设备中，不会上传到服务器。清理浏览器网站数据会同时清除本机保存的测量记录，请定期导出 XLSX 备份。

## 本地运行

这个项目是纯静态网页，不需要安装依赖。直接打开 `index.html`，或在项目目录启动任意静态文件服务器：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 部署

项目是一个无需构建步骤的静态站点，入口文件为仓库根目录的 `index.html`。仓库已通过 GitHub Pages 从 `main` 分支根目录发布；后续修改并推送到 `main` 分支后，GitHub Pages 会自动重新部署。
